## 1. 做了什么

死亡通知原本只有"谁死了、死于什么"。现在末尾多一句：

```
Tori has died: bled out  3 bodies await burial
Tori 死了：血流干了  3 具尸体等待安葬
```

**零具时不加这句**——一行已经带了坏消息，再补一个"0 具"只是噪音。

---

## 2. 为什么不做独立计数器 UI

| 方案 | 代价 | 判断 |
| --- | --- | --- |
| 殖民地页常驻一行"未安葬 N" | 需要页面改动 | 数字长期为 0，等于装饰 |
| **并在死亡通知里** | 一行字 | ✅ 只在有东西可说的时候说 |
| 常驻 HUD | 界面工作 | 之后 M3 再说 |

**这与项目一贯的规则一致：卡片/提示只在该说话时说话**（VERIFY-052/059 同一原则）。
