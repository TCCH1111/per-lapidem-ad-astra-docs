## 1. 本轮做了什么

无论"谁"来包扎，**动作是同一个**：

```java
HealthContent.dress(state, who, pack)
  1. 找到这个人第一处仍在流血的伤口
  2. 从容器里取一片绷带
  3. 标记该伤口已处置（止血 + 不再感染）
```

**没有绷带、或没有伤口 → 什么都不做，且不消耗绷带。**

—— 这是两条候选路线（A 自助 / B 医生）**共同**的核心，所以先做它。

---

## 2. 为什么写成"簿 + 容器"的函数

它不需要殖民地、不需要世界，因此：

- 测试可以直接喂一个 `HealthState` 和一个 `SimpleContainer`；
- 将来 A 或 B 的触发器只是"**在什么时机调用它**"，不用重写规则。
