## 2. 死亡是怎么发生的

殖民地**每秒清扫一次**：

```
血 ≤ 0  或  任一部位感染 = 100
        ↓
先写讣告（名字只有尸体还在时才读得到）
        ↓
mob.kill()            ← 引擎自己的移除路径，会通知殖民地"这个身体没了"
        ↓
从健康簿忘掉这个人      ← 第二次清扫不会再死一次
```

**为什么先写讣告再杀**：名字是从实体上读的；杀完再读就只剩"someone"。
