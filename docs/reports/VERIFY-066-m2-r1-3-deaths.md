## 1. 为什么先做这一层

PRD-009 的 **G2** 要求：*每次死亡都有讣告 + 葬礼或明确未安葬状态 + 关系人记忆变化*。

而 R1-2 还有三个未定项：死亡触发（血/感染/任一）、尸体形态、讣告记在哪。
**但这三件事不影响"要不要留一条死亡记录"**——无论答案是什么，殖民地都得能说清
**谁死了、死于什么、什么时候**。

所以这一层可以现在做，且做错了也不亏。

---

## 2. 做了什么

| 内容 | 说明 |
| --- | --- |
| `HealthState.Death(who, name, cause, at)` | 一条死亡记录：谁、叫什么、死于什么、何时 |
| `record(Death)` / `recentDeaths(n)` / `deathCount()` | 记录、**新的在前**、条数 |
| 空缺兜底 | 没有名字 → `someone`；没有死因 → `unknown`（不写空行） |
| 存读 | 与健康簿同一份存档 |
