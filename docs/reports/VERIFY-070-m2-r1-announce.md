## 1. 补上的那句话

在此之前：居民会死、殖民地在簿上记了一笔——**而玩家只会发现少了一个人**。

现在死亡会广播一行：

```
Tori has died: bled out
Tori 死了：血流干了
```

死因不是硬编码字符串，而是走一张**映射表**：

| 内部死因 | 语言键 |
| --- | --- |
| `bled out` | `folkways.health.cause.bled_out` |
| `infection` | `folkways.health.cause.infection` |
| 其它 | `folkways.health.cause.unknown` |

**为什么要有映射**：新增一种死因时，若忘了加键，玩家会看到原始键名而不是人话——
把映射收在一个函数里，就只有一个地方会忘。

---

## 2. 四语键（各 4 条）

| 键 | en | zh_cn |
| --- | --- | --- |
| `health.died` | `%s has died: %s` | `%s 死了：%s` |
| `cause.bled_out` | `bled out` | `血流干了` |
| `cause.infection` | `an infection` | `伤口感染` |
| `cause.unknown` | `a cause nobody knows` | `不明原因` |

（zh_hk / zh_tw 各自成文，非简繁硬转。）
