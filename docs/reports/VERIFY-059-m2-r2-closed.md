## 3. R2-4：卡片说什么

| 情形 | 卡片 |
| --- | --- |
| 仇人在旁 | 「和不对付的人一起干活，心里不痛快」+「把他们分开放」 |
| 朋友在旁（无仇人） | 「有个朋友在旁边一起干活」+「排在一起…」 |
| 两者都在 | **只说仇人那条** |
| 都没有 | 零行 |

**为什么两者都在时只说仇人**：玩家能采取的行动是"分开"，而朋友那条是"放在一起"——
同时显示会给出互相矛盾的建议。**卡片必须能回答"我该做什么"，不能同时说两件事。**
