## 2. R1-1 做了什么

| 内容 | 说明 |
| --- | --- |
| 感染按**部位**记录（0–100） | 与 PRD 的 `part.infection` 对齐 |
| **感染的判定是纯函数** | `maybeInfect(who, part, roll)`：`roll < 10%` 才感染 |
| 每天加深 6 点 | 约 10 天到 PRD 的坏死门槛 60 |
| 到 60 计入"重伤" | 复用已有 `severe()` → 已有"停止派活"链路 |
| 存读 | 感染随殖民地保存 |

**关键选择**：那枚骰子**作为参数传进来**，不在函数里摇——
这样"坏运气"是可复现的，测试能直接说清"roll=0.01 时发生什么"。

## 3. 四个测试

| 测试 | 断言 |
| --- | --- |
| `infectionIsAPureFunctionOfTheRoll` | 低 roll 感染、同一部位不会二次感染、高 roll 不感染 |
| `infectionDeepensByTheDay` | 三天后更深；一千天后**封顶 100** |
| `deepInfectionCountsAsSevere` | 刚感染不算重伤；过门槛 → 坏死 + 停止派活 |
| `infectionSurvivesASave` | 感染度往返一致 |

## 4. 为什么这一轮没有卡片
