## 1. 补上的那半个问题

`ZoneRule` 原本有三种 Kind，都在回答"**这一格**允许谁"：

| Kind | 语义 |
| --- | --- |
| `FORBID` | 谁都别进（可限定主体） |
| `ALLOW_ONLY` | 只有列出的主体能进 |
| `LIMIT` | 最多 N 个主体同时在 |

关押需要的却是反向问题：**对某个人，除了这片，别处都不许去。**

新增 `CONFINE` 正是这个语义：

| 位置 | 被列出的主体（囚犯） | 其他人 |
| --- | --- | --- |
| **区内** | `ALLOWED` | `ONLY_FOR_OTHERS`（牢房不让闲人进） |
| **区外** | **`FORBIDDEN`** | `ALLOWED`（不受影响） |
| 主体列表为空 | 什么都不做 | 什么都不做 |

---

## 2. "空列表什么都不做"是有意的

别的 Kind 里空列表 = 对所有人生效（`FORBID` 的既有语义）。
`CONFINE` **不能**沿用：那会变成"把所有人关在什么都没有的区域外"——一个静默的世界级陷阱。

所以：**没点名谁，就谁也不关**。这条语义写进了枚举注释与测试。
