## 3. 五档边界（测试逐条钉住）

| 输入 | 心情 |
| --- | --- |
| 饱、睡足、有活等着 | `CONTENT` |
| 基底判定为紧急的饿或困 | **`DESPERATE`**（压过一切） |
| 饥饿 ≤ 1/4，或清醒 ≤ 1/4，或刚被拒 | `STRESSED` |
| 饥饿 ≤ 1/2，或清醒 ≤ 1/2，或没有活等着 | `WORRIED` |
| `null` 快照 | `CONTENT` |

"被拒也算压力"这条是有意为之：**长期闲着但吃得饱**的居民，在殖民地模拟里同样是需要处理的状态。

---

## 4. 一条设计约束（写进代码注释）

> **每档必须能回答"玩家该做什么"；回答不了就不加这一档。**

这是 VERIFY-031/033 那两轮的教训：**没有证据的原因不该对玩家说**；同理，**没有行动建议的心情档只会变成又一套数字**。四档的建议分别是"无需处理 / 找点活或让他早点吃 / 喂饱休息或排查谁挡他 / 现在就让他吃或睡"。
