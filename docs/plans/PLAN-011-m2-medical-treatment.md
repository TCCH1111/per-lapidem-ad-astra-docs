## 1. 现在缺的是什么

伤能流、能感染、能死人、能埋人——**唯独不能救**。

而要"救"，技术上只差一步：**谁在什么条件下把绷带用在伤口上**。
数据层早就有了（`HealthState.treat(who, part)`：处置后停止流血、且不再感染）。

---

## 2. 两条路（需要你选一条）

### 路 A：居民自己包扎（我推荐先做）

| 项 | 内容 |
| --- | --- |
| 触发 | `Urge`：有未处置伤口且身上有绷带 → 停下手里的事自我处置 |
| 前置 | 绷带从哪来：**先从背包**（合成/搜刮留给后续）；没有绷带就继续流血 |
| 效果 | 停止流血、该部位不再感染；**不解感染**（已感染的仍要医生） |
| 代价 | L1；复用 `Urge` + 现有节点写法；不需要新工种 |
| 风险 | 玩家可能觉得"居民自己会治"太自动；但符合 ADR-013（禁止手动微操） |

### 路 B：医生工种

| 项 | 内容 |
| --- | --- |
| 触发 | 新工种 `medic`（照 `militia` 先例）；医生用 urge 去处理伤员 |
| 前置 | 工种注册 + 工作内容分配 + 走到病人身边 |
| 效果 | 与 A 相同，但可加熟练度修正（R-MED-8 的第一步） |
| 代价 | L1 + 工种/工作节点，明显更大；且"没有医生时伤员只能等死"需要额外兜底 |
| 风险 | 玩家若不派医生，医疗等于不存在 |

**我的建议**：先 A，把"能救"这件事跑通；B 作为后续（熟练度、病房、药品三要素一起做）。

## 4. 验收（选 A 时）

| 判据 | 怎么验 |
| --- | --- |
| 有伤的居民会自己用绷带 | gametest：`urges()` 出现处置冲动 |
| 处置后不再流血 | `bleed()` 后血量不变 |
| 处置后不再感染 | `maybeInfect` 对已处置部位返回 false |
| 没绷带就继续流血 | 无绷带时无处置冲动 |
| 默认零影响 | 无伤者 1518 基线不退 |
