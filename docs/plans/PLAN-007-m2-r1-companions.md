## 2. 切片内容

### 2.1 一句话

> 两个人总在一起干活，就会成为伙伴；伙伴一起干活时心情更好——
> **所以你要决定把谁和谁排在一起**。

### 2.2 机制

| 环节 | 规则 |
| --- | --- |
| 采样 | 每 N 刻采一次殖民地居民的**位置与是否在干活**（N 待定，先按 100 刻 ≈ 5 秒） |
| 判定 | 两名"正在干活"的居民距离 ≤ 8 格 → 各自对对方的 `bond` +1（每 0.5 小时最多一次，用 `lastTouch` 卡） |
| 上限 | 每人最多 30 条关系（PRD `relation_cap` 默认值），超了淘汰 `bond` 最低且最久未更新的 |
| 士气 | 若**双方 bond ≥ 40（朋友）且此刻都在干活且距离 ≤ 8** → mood 的 `workWaiting` 之外多一个正向输入 |
| 展示 | 居民卡多一行：「和 X 一起干活，心情不错」（仅当加成生效时）；普通 bond 不刷屏 |
| 解释 | 用 `Explanation` 的单一映射点，说清"他今天心情好，是因为和 X 一起干活" |

### 2.3 决策在哪里

| 决策 | 代价 |
| --- | --- |
| 把朋友排在同一片工作区 | 士气加成 → mood 更好 → 更少 `STRESSED` |
| 把朋友拆开（分区、错班） | 没有加成；但可能换来别的排布收益（例如把某人调去更需要的岗位） |
| 让陌生人先一起干 | bond 会慢慢长起来 → 中期变成可用的"士气管道" |

**这就够了**：玩家开始有理由关心"谁和谁在一起"，这正是 PRD-008 想要的"人事安排变成有内容的选择"。
