> 进程的判定标准只有一条：**每个时代是否给玩家新的动词**。数值 +10% 不算时代。

---

## 1. 设计目标

| 编号 | 目标 |
| --- | --- |
| G1 | 每个时代 ≥2 个**只有该时代才能做**的动词 |
| G2 | 每个时代解除上一个时代的**主要瓶颈**，但引入新的瓶颈 |
| G3 | 时代推进不是「研究点数堆满」，而是**达成世界条件 + 做出选择** |
| G4 | 时代可被玩家**延迟或跳过部分内容**（自由：可以做一个石器乌托邦，但要承受后果） |
| G5 | 每个时代有**一套新的压力**（对应 d04/d06/d07），否则会变成纯升级 |

## 3. 时代推进机制

### 3.1 推进条件（三段式）

```
推进到下一时代需要同时满足：
A. 物质条件（世界中的东西）：足够的建筑、物资、人口、稳定度
B. 知识条件（做过的事）：完成过某些「里程碑行为」（如首次熔炼、首次铁路通车）
C. 选择条件（玩家的决定）：在若干「时代方向」中选一个（或选择不推进）
```

| 条件 | 例（工程/铁器时代） |
| --- | --- |
| A 物质 | 人口 ≥ 25、有矿石供应链、有稳定燃料、有铁匠工坊 |
| B 知识 | 完成过深井开采、完成过一次熔炼、完成过一座桥/一段铁路 |
| C 选择 | 「重工业（产能优先）」/「交通（物流优先）」/「军事（防御优先）」——影响后续解锁倾向 |

**R-AGE-1**：**不使用「研究点数」作为唯一门槛**。科研可以存在（学者/图书馆带来加速），但不能是唯一通路。
**R-AGE-2**：时代推进必须是**玩家的显式决定**（可以推迟，推迟有代价：更多威胁/机会流失）。
**R-AGE-3**：「选择条件」不是排他锁死——未选的方向后期仍可补，只是更贵。

### 3.2 时代的「软门槛」

| 概念 | 说明 |
| --- | --- |
| 时代解锁（Unlock） | 某些物品/建筑/职业在时代达成后才可制造/指派 |
| 时代能力（Capability） | 某些行为需要时代能力（如勘探矿脉、制造钢、操作机械） |
| 时代声望（Renown） | 对外影响（更远的商队、更认真的外交） |
| 时代代价（Burden） | 每进入一个时代，某些压力永久上升（例如财富系数、敌人强度、疾病传播） |

**R-AGE-4**：**代价必须显式**给玩家看（进入工业时代 → 敌人强度 ×1.5、疫病传播 +30%），让「要不要进入」成为真正的选择。

## 4. 科技与知识（辅助层）

| 机制 | 说明 |
| --- | --- |
| 知识（Knowledge） | 由「做过的事」积累（经验型），而非抽象点数 |
| 学者与图书馆 | 加速知识积累、解锁进阶配方、传承（学者死后知识保留在图书馆） |
| 配方发现 | 部分配方通过探索/贸易/失败获得（例如失败会教你别这么做） |
| 图纸（Blueprint/Schematic） | 外来图纸（贸易/战利品）可解锁玩家不会造的建造物（接 Create 蓝图） |
| 失传风险 | 如果只有一个专家且他死了，某些知识可能暂时不可用（但应可从图书馆恢复，避免永久损失） |

**R-AGE-5**：知识**不应因单一居民死亡而永久丢失**（那样太残忍且不可控）。图书馆/记录是保险。

## 5. 与世界的耦合

| 时代 | 世界层的变化 |
| --- | --- |
| 落脚 | 只关心数百方块 |
| 定居 | 关心周边生物群系与水源 |
| 分工 | 与商队接触（中层开始活跃） |
| 工程 | 地下与跨区运输（垂直 + 区域） |
| 规模 | 区域经济与污染/卫生（影响本地生态） |
| 远征 | 世界地图（远层）成为主要舞台 |
| 星辰 | **多世界**：轨道（空间站）+ 地表世界（多方块火箭作为唯一通道，[ADR-011](../00-charter.md)） |

**R-AGE-6**：**世界层的展开必须与时代同步**，否则会出现「石器时代就在跟星际文明做生意」的荒谬。

### 5.1 星辰时代的形态（2026-10-18 定，ADR-011）

| 项 | 决定 |
| --- | --- |
| 通道 | **多方块火箭**：由居民按图案/工地流程**逐步建造**（不是"点一下合成"），燃料/结构/载荷各自是真实物资 |
| 目的地 | **可居住空间站**（不是"上去看一眼"的风景维度）：居民能在站内生活、劳动、生产 |
| 居民参与 | 建造（复用 `build` 的工地与逐轮生长）、装载、搭乘（复用 `Passage`/`Conveyance` 载具语义）、在站生活（需求系统在太空维度同样生效：氧气/温度/食物/社交） |
| 失败模式 | 发射失败、结构损伤、补给中断、迫降、失联 → 每一种都必须有前兆与应对（P3/P5） |
| 生产 | 站内必须能自持（水/氧/食物循环），形成**新的生产链**（时代的新玩法，而不是新数值） |
| 模拟 | 空间站作为**独立维度或子层**；远离时按抽象层结算（[世界与模拟](04-world-and-simulation.md)），不加载区块仍推进 |
| 技术选型 | **已定（[r09](../research/09-space-endgame.md)）**：**主线自研**（候选 C）——火箭用 `build` 的图案/逐轮生长 + `colony.submit` 由居民建，空间站走**独立维度**（`Colony.views` 按维度天然分图），飞行第一版是**剧本式状态机**（一次跨 Realm `Hop`），**不做飞行动力学**；**备选**候选 B（Create/Sable 移动结构，居民"站上移动结构"已由 `SablePassage` 打通）；Ad Astra 只作维度与环境素材；AR3（ARR+beta）与 Stellaris（NC）**不进主线、不作编译期依赖** |

**R-AGE-10**：太空阶段**不得**自造新的核心 Node 类型——`build` 的图案/`Growing`/`BuildPlanner.complete` 已覆盖「居民逐步建造」（[r09 §3.1](../research/09-space-endgame.md)）。
**R-AGE-11**：太空插件必须自报**独立预算**（与出行预算 `travelCeilingMicros=8000` 分开立账），并按 [性能预算](../pack/03-performance-budget.md) R-PB-7 提交探针。

**M4.0 三个前置 spike（先证明接口通，再立项）**：
1. 注册一个测试 `Passage`：Overworld 上船 → 自制空维度下船，验证 `Roaming` 的**跨 Realm `Crossing`**（依据 `Roaming.java:789-803`）。
2. 一条**三阶段最小 Starlark 图案**当作"火箭"，用 `BuildPlanner.complete` 判定建成（依据 `BuildPlanner.java:73-89`）。
3. 一个新 urge（如 `OXYGEN`）挂到 `Contributions.urges`，与基底 `Hunger` 同构（依据 `Hunger.java:29-101`）。

**R-AGE-9**：太空阶段的每一步都必须**可被居民执行**（建造、装载、驾驶、维护、生活）；任何"只有玩家能做"的太空步骤都视为设计缺陷（[ADR-013](../00-charter.md)）。

## 6. 时代与难度曲线

```mermaid
flowchart LR
    A0["落脚<br/>压力：生存"] --> A1["定居<br/>压力：农时"]
    A1 --> A2["分工<br/>压力：外部人"]
    A2 --> A3["工程<br/>压力：供能与深度"]
    A3 --> A4["规模<br/>压力：组织与卫生"]
    A4 --> A5["远征<br/>压力：距离与外交"]
    A5 --> A6["星辰<br/>压力：极端环境"]
```

| 参数 | 随时代的变化 |
| --- | --- |
| 敌人强度 | ×1.0 → ×3.0+ |
| 疾病传播 | +0% → +30%+ |
| 物流需求 | 小 → 极大 |
| 单次决策影响面 | 小（一个人饿） → 大（全城供能中断） |
| 恢复成本 | 低 → 高 |

**R-AGE-7**：难度上升必须**对应玩家的能力上升**（更多工具、更好诊断、更多冗余），否则就是纯粹的压迫。

## 7. 与基底（Folkways）的关系

| 需求 | 基底状态 | 说明 |
| --- | --- | --- |
| 配方与制造链 | 已有 `plugins/wares`（`CraftRecipes`、`Smelt`、`Stations`、`Machines`） | 时代门槛可挂在配方可用性上 |
| 建造图案 | 已有 Starlark 图案（road/mine/quarry/railway/terraced_field/city_wall/dock/arch_bridge/arcade/grading/materials） | 图案可按时代解锁 |
| 铁路 | 已有 `plugins/rail`（时刻表、站点、载客） | 工程时代的核心动词之一 |
| Create 集成 | 已有（图纸建造、列车驾驶、包裹网络） | 工程/工业时代的机械基础 |
| Sable/Aeronautics | 已有集成（子层级/飞船） | 远征时代的载具基础 |
| 时代作为系统 | **无** | 全新（PRD-011） |

**关键判断**：基底的 wares/rail/build 三大插件已经覆盖了「工程」与「工业」时代的大部分动词。**我们需要补的是：时代门槛系统、知识/学者、远征与星际、以及每个时代的新压力。**
