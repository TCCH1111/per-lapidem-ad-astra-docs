## 1. 设计目标

| 编号 | 目标 |
| --- | --- |
| G1 | 世界必须**可被规划**：季节与资源有规律，玩家能提前准备（管理的回报） |
| G2 | 世界必须**会变化**：天气、生态、资源枯竭、物种迁徙让同一块地随时间不同 |
| G3 | 世界必须有**边界与远方**：殖民地之外存在可去的地方、可交易的势力、可探索的秘密 |
| G4 | 世界必须**可改写**：世界生成、资源丰度、季节长度、灾难频率都能被配置/数据包/剧本调整 |
| G5 | 世界的复杂度**不得压垮 tick 预算**：远处世界用抽象层模拟，近处才逐实体模拟 |

## 2. 时间模型

| 尺度 | 定义 | 玩家可感知 | 关联系统 |
| --- | --- | --- | --- |
| **Tick** | 20/秒（Minecraft 原生） | 不可感知 | 移动、劳动、战斗 |
| **游戏日** | 1 天 = 24000 tick ≈ 20 分钟（可配置） | 作息、饥饿、疲劳 | 作息表、劳动结算 |
| **季节** | 1 季 = N 游戏日（默认 8 天，可配置） | 作物、气温、迁徙 | 农业、保暖、储粮 |
| **年** | 4 季（默认 32 天） | 人口变化、灾祸周期 | 世代、外交、进程 |
| **时代** | 玩家的技术阶段（非线性时间） | 解锁新玩法 | 进程（见 d08） |

**规则**
| 编号 | 规则 |
| --- | --- |
| R-TIME-1 | 时间可暂停（单人默认允许，多人可配置）；暂停时 UI 仍可操作。 |
| R-TIME-2 | 提供倍速（1×/2×/4×/8×，可配置上限）；倍速不改变模拟精度（只改变每 tick 的世界时间步长）——**若基底采用固定步长，则倍速必须通过提高 tick 频率实现，性能预算需同步上调**（待 `research/01` 确认）。 |
| R-TIME-3 | 关键事件（袭击、死亡、婚育）在倍速下必须仍然可读（自动降速或弹出提示）。 |
| R-TIME-4 | 所有周期性系统（生产、生长、衰减）必须在同一结算节拍上，避免各自为政的 N 个计时器。 |

## 3. 世界结构

### 3.1 三层世界模型

| 层 | 范围 | 模拟精度 | 内容 |
| --- | --- | --- | --- |
| **近层（Local）** | 殖民地及周边（默认加载区块） | 逐实体、逐方块 | 居民、动物、机械、建筑、地块（Zone） |
| **中层（Region）** | 同区域内的其它殖民地与地貌 | 抽象（按日/按事件结算） | 外邦殖民地、商路、野地、遗迹 |
| **远层（World）** | 整个世界/维度 | 抽象（按季/按事件结算） | 势力、气候带、远方大陆、星际前哨 |

**R-W-1**：中层与远层**不加载区块**，只维护数据结构与事件；玩家前往时再实例化（进入近层）。
**R-W-2**：抽象层的结算必须与近层一致（同一处贸易在中层近层给出相同结果），避免「走近就变样」的欺骗感。

### 3.2 垂直结构

| 层 | 内容 | 新玩法（对应时代） |
| --- | --- | --- |
| 天空 | 飞艇/飞船航线、浮空据点 | 蒸汽时代 |
| 地表 | 农田、牧场、林地、河湖、道路 | 农耕时代 |
| 浅层地下 | 地窖、矿洞、地下仓储 | 铜石时代 |
| 深层地下 | 矿脉、地下水、熔岩、洞穴生态、遗迹 | 铁器时代 |
| 地下深处 | 危险区（高温/毒气/塌方/深层生物）、稀有资源 | 工业时代 |

**R-W-3**：地下必须提供**风险/回报的抉择**（深 = 更好资源 + 更高死亡风险），而不是单纯的资源层。

**垂直结构的"另一层"（2026-10-18 定，ADR-016）**：除方块层之外，世界还有一层**不可见但可被规划**的空气层——**分区池 + 边界梯度**（[d13](13-gases-pollution-and-cycles.md)）。它决定：地下深处的毒气/可燃气、密闭厂房里的 CO₂ 堆积、烟囱把烟吹到谁的菜地上、以及**场地温度场**（**统一由它提供，本文件的 §4.2 温度只是它的一个消费方**，不再另建第二套）。M3 只预埋接口，M4 完整实现。

### 3.3 玩家的「远方」

| 内容 | 形态 | 时代 |
| --- | --- | --- |
| 探索遗迹 | 结构生成 + 事件 | 铜石 |
| 商路与商队 | 抽象路线 + 近层到达 | 铜石 |
| 外邦殖民地 | 中层抽象 + 可亲访 | 铁器 |
| 远征据点 | 玩家在远方建立二级殖民地（抽象近层混合） | 蒸汽 |
| 跨维度/星际 | 独立世界 + 物流链 | 星辰 |

## 4. 气候、季节与天气

> **实现路线已定（ADR-010，2026-10-18）**：季节/温度**在 fork 内自研**，作为**可被规划器读取的世界数据层**；
> 外部 mod（Cold Sweat / Serene Seasons）只作**可整套删除的可选传感器**（[r08](../research/08-temperature-thirst-integration.md)：Cold Sweat 能扩展到任意实体但行为后果要自写、NPC 降频 ×40、许可声明冲突；Serene Seasons 是世界级季节但有真 API 且为 **ARR**）。
> **引擎现状**：基底**零环境感知**（只有 `getSkyDarken`/`getDayTime`）→ 本节所有内容都是我们要新建的。
> 详细设计（温度场采样、vitals、食物与营养、预测）见 [PRD-003](../prd/PRD-003-season-temperature-thirst-nutrition.md)。

### 4.1 季节

| 季节 | 温度修正 | 农业 | 生态 | 玩家压力 |
| --- | --- | --- | --- | --- |
| 春 | 回升 | 播种 | 迁徙归来、繁殖 | 抢农时 |
| 夏 | 高 | 生长/部分收获 | 虫害、林火风险 | 用水、防旱 |
| 秋 | 下降 | 收获（关键窗口） | 动物储能、捕食增加 | 抢收、储粮 |
| 冬 | 低 | 无（温室除外） | 食物稀缺、捕食者靠近殖民地 | 保暖、耗粮、士气 |

**R-CL-1**：季节长度可配置；「生长季长度」是难度的主要旋钮之一（更短 = 更硬）。
**R-CL-2**：必须能在游戏内看到**未来一段时间的天气预报**（预报准确率本身可作为进程解锁内容）。

### 4.2 温度与保暖

| 项 | 内容 |
| --- | --- |
| 温度来源 | 生物群系基温 + 季节 + 昼夜 + 天气 + 海拔 + 室内 |
| 室内判定 | 有顶 + 有墙 + 有门（复用 Minecraft 的遮蔽语义，若基底已有则复用） |
| 保暖手段 | 衣物、火源、建筑密闭、体热（同处一室温热）、被褥 |
| 后果 | 体温过低 → 效率下降 → 生病 → 死亡；过热 → 中暑 |

**R-CL-3**：温度必须**可被玩家建造与衣物解决**，且解决方案有成本梯度（火把 < 篝火 < 壁炉 < 供暖系统）。

### 4.3 天气与天灾

| 事件 | 前兆 | 影响 | 应对 |
| --- | --- | --- | --- |
| 暴雨/雷暴 | 云层/气压预报 | 作物受损、火灾、心情下降 | 排水、避雷 |
| 暴雪/寒潮 | 温度预报 | 保暖压力、行动受阻 | 储备、建筑密闭 |
| 干旱 | 长期无雨 | 作物减产、水源下降 | 灌溉、蓄水 |
| 林火 | 干燥 + 雷击/疏忽 | 烧毁林地与建筑 | 防火带、水渠 |
| 洪水 | 暴雨 + 地形 | 冲毁低地 | 选址、堤坝 |
| 虫害 | 季节 | 作物减产 | 轮作、药草、放养天敌 |
| 地震/塌方 | 采矿活动 | 矿井损坏、死亡 | 支护结构 |

**R-CL-4**：每种天灾都要有「可预防 / 可缓解 / 可承受」三条路径（对应支柱 P3 的验收信号）。
**R-CL-5**：天灾必须有前兆（对应 R-RHYTHM-1）。

## 5. 生态与资源

### 5.1 生态

| 元素 | 行为 | 与殖民地的互动 |
| --- | --- | --- |
| 食草动物 | 迁徙、繁殖、被猎 | 肉/皮/毛/驮运；过度捕猎导致减少 |
| 捕食者 | 领地、饥饿、袭击牲畜与人 | 威胁；可被驱赶/猎杀/驯化 |
| 鱼类 | 水域存量 | 渔业（基底已有 fishery 区块） |
| 林木 | 生长/再生 | 木材；过度砍伐导致水土流失/生态退化 |
| 土壤肥力 | 随耕作下降，休耕/施肥恢复 | 农业可持续性 |
| 传粉/益虫 | 提升产量 | 保护生态的收益（鼓励不全灭） |

**R-ECO-1**：资源**可再生但有限**（过度采伐有代价），避免「无限刷资源」的枯燥，也避免「资源耗尽就废档」的绝望。
**R-ECO-2**：生态变化必须可见（例如林地消退、鹿群减少），让玩家能观察到自己的影响。

### 5.2 资源与矿脉

| 资源类 | 分布 | 可再生 | 时代 |
| --- | --- | --- | --- |
| 木/植物纤维 | 地表林地 | 是 | 石器 |
| 石/黏土/砂 | 地表/浅层 | 否（近无限） | 石器 |
| 铜/锡 | 浅层矿脉 | 否 | 铜石 |
| 铁/煤 | 中层矿脉 | 否 | 铁器 |
| 稀有金属/宝石 | 深层、危险区 | 否 | 工业 |
| 地下水/地热 | 深层 | 视情况 | 工业 |
| 特殊资源（末期） | 远方/维度 | 否 | 星辰 |

**R-RES-1**：矿脉必须能被**勘探**（对应时代解锁探矿能力），而不是玩家盲目乱挖。
**R-RES-2**：资源分布受剧本参数控制（丰饶/贫瘠世界）。

## 6. 世界压力总表（环境侧）

> 这是 [威胁与叙事](07-threats-and-narrative.md) 的输入之一。环境压力只负责「自然」，不含敌对势力。

| 压力 | 时间尺度 | 前兆 | 预防 | 缓解 | 承受 |
| --- | --- | --- | --- | --- | --- |
| 饥饿 | 日/季 | 存粮下降、体重下降 | 规划农时、储粮 | 节食、狩猎、贸易 | 减员后恢复 |
| 严寒 | 季 | 温度预报 | 保暖建筑、储燃料 | 集中居住、临时火源 | 效率下降、疾病 |
| 疫病 | 周/月 | 咳嗽、卫生差 | 卫生设施、隔离 | 药物、隔离区 | 减员、群体免疫 |
| 天灾 | 随机 | 多种 | 选址、工程 | 抢修、救济 | 损失后重建 |
| 资源枯竭 | 长期 | 产量下降 | 轮作、勘探 | 贸易、替代材料 | 迁移或转型 |

## 7. 与基底（Folkways）的关系

| 我们需要的 | 基底已提供（待 `research/01` 确认具体类） | 需要新增 |
| --- | --- | --- |
| 世界空间与坐标 | `core/api/terms/WorldSpaces`、`WorldPos` | 抽象层（Region/World） |
| 地表变化 | `core/api/ground/Ground`、`BlockChanges` | 生态/肥力追踪 |
| 时间节拍 | `core/engine/labor/SimulationClock` | 季节/年历、倍速 |
| 天气 | 无（Minecraft 原生天气） | 季节化天气 + 前兆 + 影响 |
| 生物群系 | 原生 | 温度/资源/生态修正 |
| 区块加载管理 | 原生 | LOD 与抽象层 |

**R-W-API-1**：季节与年历必须作为**全局世界状态**（随世界存档保存），不能是每个殖民地各自维护。
**R-W-API-2**：抽象层（Region/World）必须能在**不加载区块**的情况下结算，否则违反 G5。

## 8. 数据与性能

| 项 | 策略 |
| --- | --- |
| 季节/年历 | 世界级少量数据，每 tick 无成本（按日结算） |
| 天气 | 按日结算 + 少量状态，不做逐 tick 全图计算 |
| 生态 | 按区块的稀疏采样（例如每区块存 1 个「生态值」），按日/季结算 |
| 肥力 | 每地块（Zone）一个数值，随耕作/休耕变化 |
| 矿脉 | 世界生成时确定，不动态计算 |
| 抽象层 | 每季/每事件结算，O(实体数) 且实体数上限受控 |

**性能红线**：不得新增逐 tick 遍历全部区块的系统；所有环境系统必须在「日结算」节拍上运行。
