# 威胁、防卫与故事生成

```
状态：草稿
负责人：设计
最后更新：2026-10-17
上游依据：docs/design/01-vision-and-pillars.md（P3 世界会回应、P5 失败长出故事）、docs/design/02-benchmark.md
下游影响：PRD-002（事件与叙述者）、PRD-004（威胁、袭击与防卫）、传说页实现
```

> 这是「好玩」的主要来源：**压力 + 决策 + 后果**。
> 但也最容易做坏：无预警的天罚、重复的事件、没有意义的战斗，都会迅速杀死游戏。
> 本文件定义威胁的种类、事件的形状、叙述者的调峰机制、以及战斗与外交的边界。

---

## 1. 设计目标

| 编号 | 目标 |
| --- | --- |
| G1 | 每种威胁都有**前兆 → 应对窗口 → 结果 → 余波**的完整链条 |
| G2 | 玩家的每种应对都有代价（建墙占人力、屯粮占空间、扩军占口粮） |
| G3 | 事件**不重复**：同一模板在不同人/不同条件下产生不同故事 |
| G4 | 战斗**不吞掉游戏**：和平叙述者下可以完全不战，且不因此失去进程 |
| G5 | 失败**可承受**：单次危机不应导致全灭（除非玩家自选残酷 + 长期忽视） |
| G6 | 所有威胁的强度与频率**可调**（配置/叙述者/剧本） |

**反目标**：不以「打怪」为核心循环；不做需要玩家亲自战斗才能推进的主线。

## 2. 威胁分类

| 类别 | 来源 | 例 | 应对维度 |
| --- | --- | --- | --- |
| **环境** | 世界（见 [世界与模拟总纲](04-world-and-simulation.md)） | 严冬、干旱、林火、洪水、塌方 | 工程、储备、选址 |
| **生态** | 生物 | 野兽袭击牲畜、虫害、猛兽 | 围栏、狩猎、驱赶 |
| **人（外部）** | 外部势力 | 流匪、掠夺者、敌对殖民地、正规军 | 防御、外交、贡赋、迁徙 |
| **人（内部）** | 居民自身 | 精神崩溃、争执、怠工、出走、叛乱 | 情绪管理、公正、分配 |
| **生物性** | 健康 | 疫病爆发、水源污染、食物中毒 | 卫生、隔离、医疗 |
| **结构性** | 自身系统 | 供能中断、物流堵塞、库存枯竭、建筑失修 | 维护、冗余、诊断 |

**R-TH-1**：任意时刻，玩家面对的威胁类别不超过 2 类（除剧本设定），避免「多线崩溃」的挫败。
**R-TH-2**：除「结构性」外，每类威胁都必须有外部世界的**叙事解释**（谁/为什么），而不是抽象数值。

## 3. 事件系统（Incident System）

### 3.1 事件模板（数据驱动）

| 字段 | 说明 |
| --- | --- |
| id / 名称 / 描述 | 玩家可见文本（**双语 `zh_cn` + `en_us`**） |
| 触发条件 | 时代、人口、季节、库存、情绪、外交、地形、前置事件 |
| 权重 | 基础权重 × 各类修正（最近发生过 → 降权，见 R-N-1） |
| 冷却 | 同类事件的冷却期 |
| 前兆（Herald） | 必须存在：信使、足迹、气味、咳嗽、气温、侦察报告 |
| 角色槽位 | 参与者/受害者/见证者（从居民中挑选，带筛选条件，如「有亲属」「情绪低」） |
| 选项 | 玩家选择（**必须包含至少一条不作为路径**），或纯观察型 |
| 结果 | 世界变化、物资变化、居民状态/情绪/关系/记忆变化 |
| 余波 | 后续事件的触发条件（事件链） |
| 记录 | 写入传说页的条目模板 |

### 3.2 事件类型（举例）

| 类型 | 例 | 玩家选项（示例） |
| --- | --- | --- |
| 观察型 | 商队路过、迁徙兽群 | 无（只影响世界与情绪） |
| 选择型 | 难民求收留 | 收留（耗粮/引矛盾） / 拒之门外（声望↓） / 暂留考察 |
| 挑战型 | 掠夺者索贡 | 付贡 / 抵抗 / 谈判 / 迁徙（搬迁殖民地） |
| 谜题型 | 水源被污染 | 查源头 / 换水源 / 烧水（费燃料） |
| 机遇型 | 发现矿脉/遗迹 | 探查（风险） / 忽略 / 派人长期开发 |
| 内部型 | 两名居民激烈争执 | 调解 / 偏袒一方 / 置之不理（关系恶化） |
| 道德型 | 疫情中的隔离抉择 | 隔离（自由受限、情绪↓） / 不隔离（扩散风险） / 第三条路：集中照料 + 招募志愿者 |

**R-TH-3**：道德两难事件**必须给第三条路**（往往是高代价但两者兼顾），否则玩家会感到被强迫。
**R-TH-4**：不作为路径必须存在，但必须有其后果（不是免费跳过）。

### 3.3 事件链（Story Arc）

| 链 | 阶段 |
| --- | --- |
| 掠夺者 | 侦察 → 索贡 → 袭击 → 撤退/占领 → 报复或议和 |
| 疫病 | 零星咳嗽 → 数人患病 → 爆发 → 高峰期 → 平息 → 后遗症/纪念 |
| 难民 | 消息 → 抵达 → 收留抉择 → 融入/冲突 → 贡献/背叛 |
| 复仇 | 结仇 → 威胁 → 冲突 → 死伤 → 血债延续或和解 |
| 繁荣 | 声望上升 → 移民潮 → 住房/食物压力 → 阶级分化 → 内部冲突 |

**R-TH-5**：事件链必须**可被玩家打断**（例如提前议和、提前隔离），且打断本身就是成就。

## 4. 叙述者（Narrator）

| 风格 | 事件频率 | 强度 | 峰值间隔 | 适用 |
| --- | --- | --- | --- | --- |
| 和平（Peaceful） | 低 | 低 | 长 | 只想建造与管理 |
| 标准（Standard） | 中 | 中 | 中 | 默认 |
| 残酷（Harsh） | 高 | 高 | 短 | 想被讲故事 |
| 自定义（Custom） | 可调 | 可调 | 可调 | 高级玩家 |

**调峰参数（全部可配置）**

| 参数 | 说明 | 默认（标准） |
| --- | --- | --- |
| `event_frequency` | 事件基础频率 | 每 3–5 游戏日一次 |
| `event_intensity` | 事件强度系数 | 1.0 |
| `peak_cooldown_days` | 两次峰值事件的最小间隔 | 3 天 + 上次冲击 |
| `early_game_grace_days` | 开局保护期 | 前 5 天只放教学型事件 |
| `min_population_for_lethal` | 团灭风险事件的人口门槛 | < 8 人不出现 |
| `storyteller_memory` | 是否记住玩家的应对倾向并调整 | 开 |

**R-TH-6**：叙述者可以「挑事」，但**不能违反 R-RHYTHM-1~4**（前兆、间隔、人口门槛、玩家可调）。

## 5. 袭击与防卫

### 5.1 袭击的形状

| 阶段 | 内容 | 玩家可做 |
| --- | --- | --- |
| 前兆 | 侦察者出现、边境脚印、逃难者带来消息 | 侦察、加固、疏散、议和、求援 |
| 集结 | N 天倒计时（可被玩家提前行动打断） | 备战、藏粮、转移老弱 |
| 来袭 | 敌人进入近层，按目标行事 | 民兵迎击、撤退入堡、陷阱、关门 |
| 交锋 | 战斗结算（居民/民兵 vs 敌人） | 指挥（若开启命令模式）、救援伤员 |
| 撤退/占领 | 敌人抢掠后离开，或就地占领 | 追击、谈判、放弃该地 |
| 余波 | 伤亡、损毁、情绪、记忆、声望、外交变化 | 重建、葬礼、复仇或和解 |

### 5.2 袭击强度公式（草案）

```
强度 = 基准 × 时代系数 × 人口系数 × 财富系数 × 叙述者强度 × 剧本修正
      × 随机波动（±20%）

其中：
  时代系数：早期 0.5 → 晚期 3.0（敌人也会进步）
  人口系数：sqrt(殖民地人口 / 10)（次线性，避免人口多就必死）
  财富系数：1 + 可见财富系数（掠夺者冲着财富来）
```

**R-TH-7**：袭击强度**必须与玩家能观察到的东西挂钩**（财富、声望、时代），让玩家理解「为什么是我」。
**R-TH-8**：财富系数意味着**炫耀财富有代价**（好东西要藏好/建墙），这是好设计。
**R-TH-9**：战斗必须允许**不战而守**（关门、躲藏、献财）——但每种都有代价。

### 5.3 防卫手段

| 手段 | 时代 | 效果 | 代价 | 维护 |
| --- | --- | --- | --- | --- |
| 围栏/栅栏 | 石器 | 挡野兽 | 木材、人力 | 修复 |
| 城墙/门 | 铜石 | 挡人 | 大量石料、工期 | 修复、值守 |
| 陷阱 | 铜石 | 削弱来袭者 | 材料、误伤风险 | 重置 |
| 塔楼/瞭望 | 铁器 | 预警、射击位 | 建材、值守人力 | 值守 |
| 民兵 | 铜石 | 直接防御 | 训练时间、平日占用人力、装备 | 训练、装备损耗 |
| 常备军 | 工业 | 更强 | 口粮、装备、政治风险（军阀化） | 军饷 |
| 避难所（地窖/堡垒） | 任意 | 保命 | 空间、工期 | —— |
| 同盟/贡赋 | 铁器 | 避免战争 | 物资/主权 | 定期 |

**R-TH-10**：任何防卫手段都必须**在和平时期有成本**（占人力/维护），否则玩家会无限堆防御。

### 5.4 战斗实现的边界（技术）

| 选项 | 说明 | 风险 |
| --- | --- | --- |
| A. 复用 Minecraft 原生战斗 + 居民实体 AI | 敌人是原生怪物/自定义实体，居民用基底 AI 迎击 | 需要给 `ResidentEntity` 加战斗行为；可能与基底 AI 冲突 |
| B. 抽象结算（不逐帧战斗） | 袭击按「回合/时段」结算，玩家看到结果与动画 | 表现力弱，但性能可控、易平衡 |
| C. 混合：近层用 A，抽象层用 B | 玩家在场时逐实体，不在场时抽象 | 实现复杂，但最符合 G5 |

**建议：C（混合）**，M1 先做 B 的抽象骨架 + 少量 A 的表现（见 PRD-004）。

## 6. 外部势力与外交（后期）

| 概念 | 说明 |
| --- | --- |
| 势力（Faction） | 外邦殖民地、商邦、掠夺者团、王国、教团 |
| 关系值（Standing） | -100（死敌）~ +100（盟友） |
| 交互 | 贸易、赠礼、使节、条约、朝贡、联姻（后期）、战争 |
| 条约 | 停战、通商、互不侵犯、共同防御、割让 |
| 情报 | 玩家对势力的了解程度（未接触 → 传闻 → 已知 → 熟悉） |
| 变化 | 势力的行为也受自身状态影响（饥荒的邻国会来抢粮） |

**R-TH-11**：外交必须给出**非战斗的解法**（用钱、用粮、用关系、用迁徙），否则 P3 会退化为纯战斗。
**R-TH-12**：势力的行为必须**可理解**（邻国抢粮是因为它饥荒，而不是随机数）。

### 6.1 外邦世界的三种供给方式（来自 [r07](../research/07-mc-landscape.md)）

我们**不必**自己造全部外部世界。三条路径按成本排序：

| 方式 | 做法 | 优点 | 风险 |
| --- | --- | --- | --- |
| **A. 纯抽象**（推荐起步） | 势力只有数据（关系值、需求、使节、商队到达事件），世界中不出现实体殖民地 | 成本最低、性能可控、与 d04 抽象层一致 | 世界感较弱 |
| **B. 整合 Millénaire** | 用 Millénaire 的村庄作为「真实邻村」，我们的 `realms` 读取/影响其声誉与贸易 | 世界感强、零自研内容 | 依赖上游 API 稳定性；两套 AI 的边界要划定 |
| **C. 整合 MCA Reborn** | 作为「外邦人（不可雇佣的 NPC）」或招募来源 | 关系/家族模型完整 | **第二套居民实体**，与 Folkways 居民语义冲突，必须严格隔离 |

**R-TH-16**：无论哪条路径，**我们自己的居民永远只由 Folkways 管**；外邦 NPC 不得进入我们的居民名册（避免两套实体与两套 AI 互相污染）。
**R-TH-17**：路径 A 是 M1–M2 的基线；路径 B/C 作为可选整合，且**不得成为唯一通路**（对应 [整合包规格](../pack/00-pack-spec.md) R-PACK-8）。

**✅ 已裁决（2026-10-18）**：外邦走 **路径 A（纯抽象）为主线**，B/C 不引入（避免"两套居民"）。且**势力模型只有一份**：贸易、贡品、援军、袭击是同一个关系（`FactionStance`，PRD-004）的不同表现。落地规格见 [PRD-010](../prd/PRD-010-diplomacy-and-trade.md)。

## 7. 传说页与编年史（故事的出口）

| 内容 | 说明 |
| --- | --- |
| 编年史（Chronicle） | 按时间的事件年表（谁、何时、何地、结果） |
| 人物条目 | 生平、关系、作品、关键记忆、死因 |
| 家族树 | 血缘与婚姻 |
| 墓园 | 死者列表与墓碑位置 |
| 势力记录 | 与各势力的互动史 |
| 统计回顾 | 人口曲线、死亡原因分布、最富有/最悲惨的年份 |
| 导出 | 导出为可读文本（markdown/HTML），便于分享（对应叙事自由的「可读」） |

**R-TH-13**：传说页只记录**真实发生过**的事，不生成虚构内容。
**R-TH-14**：玩家打开传说页时，应能快速回答三个问题：我们经历了什么？谁最重要？我们为什么变成现在这样？

## 8. 失败的边界（防止挫败）

| 保护机制 | 说明 |
| --- | --- |
| 前兆制度 | R-RHYTHM-1 |
| 早期保护 | 人口 <8 不放致命事件 |
| 减员而非团灭 | 单次危机的死亡上限随人口缩放（例如不超过 1/3） |
| 救济路径 | 逃难（搬迁）、求援（付费）、缩减（放弃扩张） |
| 恢复加速 | 危机后一段时间资源再生加快 / 不触发新峰值（冷却） |
| 可调 | 叙述者强度、关闭模块、难度参数 |
| 无惩罚读档 | 不惩罚读档；但可以有「铁人」可选项给硬核玩家 |

**R-TH-15**：任何能导致殖民地全灭的机制，都必须经过「三条路径检验」（预防/缓解/承受）。

## 10. 数据与性能

| 项 | 策略 |
| --- | --- |
| 事件调度 | 按日结算，O(可用模板数)，不逐 tick |
| 袭击 | 前兆与集结期零成本；来袭期间逐实体（受实体数上限约束） |
| 战斗结算 | 若采用抽象结算：按「时段」结算（例如每 5 秒一次），不逐帧 |
| 关系/记忆写入 | 事件结束时批量写入 |
| 范围外敌人 | 用抽象层结算（不加载区块） |

**R-PERF-3**：单次袭击的实体数上限必须明确（例如同时活动敌人 ≤ 30），超出则以批次进入。
