## 1. v1.0 的成功定义（Definition of Done）

发布一版 `v1.0.0` 时，下面六条**同时成立**才算完成：

| # | 判据 | 怎么验（可复现） |
| --- | --- | --- |
| 1 | **能装**：`.mrpack` 与 GitHub Release 两条路都能装出可玩实例 | 全新实例 → 安装器/启动器导入 → 进世界；`docs/reports/VERIFY-00x` 有记录 |
| 2 | **能跑**：客户端 0 FATAL、0 缺模型/缺贴图告警；服务端 `Done` 且在 20 TPS 边缘内 | 客户端 `latest.log` 计数；服务端 `Done` 行 + 性能探针 |
| 3 | **有骨架**：禁限区、作息表、解释层（"为什么"）、选址与建造、仓储物流可用 | 逐条对照 w05 的 WP 验收矩阵 + PRD 的 AC |
| 4 | **有内容**：任务书 ≥ 2 章可用、≥ 20 条事件模板、≥ 3 条闭环产线、≥ 1 个时代跨越体验 | 任务书在书里可读可完成；事件在编年史出现；闭环能稳态运行 |
| 5 | **有故事**：第一代 → 第二代可见，死亡/葬礼/记忆有反馈，传说页能读出"这个殖民地发生过什么" | 30 小时里程碑演示脚本（w05 §1） |
| 6 | **能维护**：fork 有 `NOTICE`、许可清单完整、上游同步演练做过 ≥ 1 次、文档与 README 登记零遗漏 | `docs/reports/SYNC-*.md`；链接/登记检查脚本 0 失败 |

**明确不在 v1.0 范围**：太空终局完整实现（M4 后段可延后到 1.1）、多人协作编辑的完整体验（M3 骨架即可）、自定义美术资源的大规模替换。
